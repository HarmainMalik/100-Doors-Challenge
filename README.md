# 100 Doors Challenge

A 2D puzzle game developed in Unity featuring a series of interactive door-based challenges.

## 🎮 About the Game

100 Doors Challenge is a puzzle game where players solve different challenges to unlock doors and progress through the game.

Each level introduces an interactive puzzle designed to test observation, problem-solving, and logical thinking.

## ✨ Features

- Interactive door-opening mechanics
- Drag-and-drop puzzle interactions
- Multiple-choice (MCQ) puzzles
- Code-input puzzles
- Score system
- Unity Input System integration

## 🧩 Puzzle Types

### Drag & Drop

Players interact with objects and use drag-and-drop mechanics to solve puzzles and reveal the required solution.

### Multiple Choice

Players answer multiple-choice questions to progress through the corresponding challenge.

### Code Input

Players enter the correct code through an interactive input interface to unlock the door.
