# 100-Doors-Challenge
A 2D puzzle game developed in Unity featuring 100 interactive door-based challenges.
## 🎮 About the Game

100 Doors Challenge is a puzzle game where players solve
different challenges to open doors and progress through
the game.

## 👩‍💻 My Contributions

- Developed interactive puzzle mechanics
- Created door-opening mechanics
- Implemented drag-and-drop interactions
- Developed MCQ-based puzzles
- Implemented code-input puzzles
- Developed the scoring system
- Worked with Unity's Input System

## 🛠️ Technologies

- Unity
- C#
- TextMeshPro
- Unity Input System
